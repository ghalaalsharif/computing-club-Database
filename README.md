# Computing Club Management System

## Project Overview
An academic database project developed to manage computing club members, student communities, activities, and resources using MySQL.

## Database Design
The project includes relational database design and SQL implementation for managing club information and the relationships between members, communities, activities, and resources.

## Key Features
* Database and table creation
* Primary keys, foreign keys, and integrity constraints
* Data insertion and retrieval
* SQL queries using JOINs and subqueries
* Aggregate queries for retrieving summarized information

## Technologies
* MySQL
* SQL
* MySQL Workbench

## Project Files
* computing_club.sql — SQL script containing the database implementation and queries.
* computing club final report.pdf — Project report documenting the database design and query results.

## Project Type
Academic team project completed as part of a Database course at Umm Al-Qura University.
